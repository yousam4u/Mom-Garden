# 엄마의 정원

새 계획서와 새 복실이 캐릭터 시트만 기준으로 다시 만든 모바일 PWA입니다.

## 기준

- 기획: `docs/00_Moms_Garden_Planning_Summary.md`, `docs/01_Moms_Garden_PRD.md`, `docs/02_Moms_Garden_Screen_Spec.md`
- 캐릭터: `docs/03_Boksil_New_Character_Guide.md`
- 기준 이미지: `public/assets/characters/bokshil-master-sheet.png`

`backup` 폴더의 이전 문서와 이미지는 현재 앱 기준으로 사용하지 않습니다.

## 실행

```powershell
npm run dev
```

주소:

```text
http://127.0.0.1:5174/
```

검사:

```powershell
npm run check
```
