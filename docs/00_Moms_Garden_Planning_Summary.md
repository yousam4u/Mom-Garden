# 엄마의 정원 Planning Summary

문서 버전: v0.1  
작성일: 2026-08-11  
상태: Draft  
작성 목적: 70대 어른이 집에서 지치지 않고 매일 반복할 수 있는 무릎 운동 모바일 앱의 MVP 방향 정리

## 1. 프로젝트 한 줄 정의

70대 어른이 앉아서, 누워서, 집안에서 안전하게 따라 할 수 있는 10~15회 기준의 가벼운 무릎 운동과 장운동을 캐릭터 음성 안내, 큰 화면, 정원 보상으로 매일 꾸준히 반복하도록 돕는 모바일 우선 PWA 앱.

## 2. 확정 사항

| ID | 내용 |
|---|---|
| DEC-001 | 주요 사용자는 70대 어른이다. |
| DEC-002 | 핵심 운동은 무릎에 부담이 적은 가벼운 집안 운동이다. |
| DEC-003 | 운동 모드는 앉아서 하기, 누워서 하기, 단계별 운동을 포함한다. |
| DEC-004 | 허리에 무리가 가지 않도록 자세 주의와 중단 안내를 포함한다. |
| DEC-005 | 캐릭터는 표정과 동작이 명확해야 한다. |
| DEC-006 | 매일 반복할 수 있도록 쉽고 재미있는 동기 구조가 필요하다. |

## 3. 핵심 가정

| ID | 가정 | 영향 |
|---|---|---|
| ASM-001 | 초기 버전은 iOS/Android 설치형 앱이 아니라 모바일 PWA로 만든다. | 스토어 심사 없이 빠른 테스트 가능 |
| ASM-002 | 의료 처방 앱이 아니라 운동 습관 보조 앱으로 설계한다. | 진단, 치료 판단, 통증 평가 자동화는 제외 |
| ASM-003 | 회원가입 없이 기기 로컬 저장으로 시작한다. | 70대 사용자의 조작 부담 감소 |
| ASM-004 | 새 복실이 캐릭터 시트를 기준 이미지로 사용한다. | 표정과 동작을 일관되게 제작 가능 |

## 5. MVP 핵심

| 영역 | MVP 내용 |
|---|---|
| 홈 | 오늘의 정원, 물뿌리개 3개, 큰 `운동 시작` 버튼 |
| 운동 선택 | `앉아서`, `누워서`, `가볍게 걷기/제자리`, `장운동` 모드 |
| 단계 | 홈에서 선택: 1단계 10회 × 3세트, 2단계 12회 × 4세트, 3단계 15회 × 5세트 |
| 운동 진행 | 큰 캐릭터 동작, 큰 숫자 카운트, 음성 구령, 쉬기/그만하기 |
| 안전 | 시작 전 통증 체크, 허리 중립 안내, 통증/어지럼/숨참 중단 안내 |
| 완료 | 물주기, 꽃 성장, 칭찬 멘트, 오늘 완료 표시 |
| 반복 | 아침/점심/저녁 부드러운 알림, 실패 페널티 없음 |

## 6. 운동 콘텐츠 초안

| 모드 | 예시 운동 | 허리/무릎 주의 |
|---|---|---|
| 앉아서 하기 | 발목 펌프, 무릎 펴기, 앉은 제자리 걷기, 발뒤꿈치 들기 | 허리를 의자 등받이에 기대거나 곧게 세우고 반동 금지 |
| 누워서 하기 | 하지직거상, 무릎 세우고 발꿈치 밀기, 발목 당기기 | 허리가 뜨면 다리를 낮게 들거나 중단 |
| 단계별 운동 | 1단계 seated only, 2단계 seated+lying, 3단계 standing support 선택 | 단계 상승은 연속 완료보다 통증 없음이 우선 |
| 집안 가벼운 운동 | 의자 잡고 뒤꿈치 들기, 짧은 제자리 걷기 | 움직이는 의자 금지, 벽/식탁 같은 안정 지지물 사용 |
| 장운동 | 복식호흡, 배 시계방향 마사지 안내, 누워 무릎 좌우 흔들기 | 허리 통증이 있으면 범위 축소, 식후 바로 강한 압박 금지 |
