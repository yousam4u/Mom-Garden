# 운동별 상세 순서와 설명 가이드

문서 버전: v0.3  
작성일: 2026-08-11  
기준 앱: 엄마의 정원  
대상 사용자: 70대 어른, 무릎과 허리에 부담이 적은 집안 운동이 필요한 사용자

## 1. 공통 안전 원칙

이 문서는 앱에서 운동 순서, 화면 문구, 복실이 음성 안내를 만들기 위한 콘텐츠 가이드다. 의료 진단이나 치료 처방이 아니며, 통증이 있거나 수술/질환 이력이 있으면 의료진 확인을 우선한다.

| 구분 | 원칙 |
|---|---|
| 시작 전 | 의자, 바닥, 침대, 지지물이 안정적인지 먼저 확인한다. |
| 운동 중 | 통증, 어지럼, 숨참, 허리 불편이 있으면 즉시 멈춘다. |
| 속도 | 빠르게 많이 하기보다 천천히 정확하게 한다. |
| 범위 | 높이 들기, 크게 움직이기보다 작고 편한 범위에서 한다. |
| 호흡 | 숨을 참지 않는다. 힘줄 때도 편하게 숨을 쉰다. |
| 보상 | 중간에 멈춰도 실패로 표현하지 않는다. 몸을 지킨 선택으로 안내한다. |


### 반복 기준

앱에서는 한 세트 안에서 10~15회를 진행하고, 단계가 올라갈수록 세트 수를 3세트에서 5세트까지 늘린다. 각 화면 단계가 바뀌는 순간 같은 단계의 음성을 재생하고, 음성이 끝난 뒤 다음 동작으로 넘어간다.

| 단계 | 한 세트 반복 | 세트 수 | 적용 기준 |
|---|---:|---:|---|
| 1단계 | 10회 | 3세트 | 처음 시작하거나 컨디션이 낮은 날 |
| 2단계 | 12회 | 4세트 | 1단계가 편해진 날 |
| 3단계 | 15회 | 5세트 | 통증 없이 익숙해진 날 |
### 공통 화면 버튼

| 버튼 | 문구 | 동작 |
|---|---|---|
| Primary | 천천히 시작 | 운동 카운트 시작 |
| Secondary | 잠깐 쉬기 | 카운트 일시정지, 쉬기 안내 |
| Safety | 아파요 | 즉시 중단, 안전 안내 |
| Stop | 그만하기 | 완료 보상 없이 홈으로 이동 |

### 공통 복실이 말투

- 존댓말을 사용한다.
- 짧고 구체적으로 말한다.
- 잔소리보다 칭찬과 안전 확인을 우선한다.
- 예: `좋아요. 천천히 하셨어요.`, `아프면 여기서 멈춰도 괜찮아요.`

## 2. 앉아서 운동

### 2.1 목적

의자에 앉은 상태에서 무릎 주변 근육과 발목을 가볍게 깨운다. 서기 어렵거나 누워서 운동하기 전 준비가 필요한 사용자에게 가장 먼저 추천한다.

### 2.2 준비물과 자세

| 항목 | 설명 |
|---|---|
| 의자 | 등받이가 있고 움직이지 않는 의자. 바퀴 의자 금지. |
| 앉는 위치 | 의자에 깊게 앉고 엉덩이를 안정적으로 둔다. |
| 허리 | 등받이에 기대도 되고, 편하게 세워도 된다. 허리를 과하게 젖히지 않는다. |
| 발 | 양발은 바닥에 편하게 둔다. |
| 손 | 의자 옆이나 허벅지 위에 가볍게 둔다. |

### 2.3 추천 루틴

| 단계 | 운동 | 횟수 | 설명 |
|---|---|---:|---|
| 1 | 발끝 당기기 | 10회 | 발끝을 몸 쪽으로 살짝 당겨 발목과 종아리를 깨운다. |
| 2 | 무릎 펴기 | 10~15회 | 허벅지는 의자에 두고, 무릎 아래 종아리만 앞으로 천천히 편다. |
| 3 | 앉은 제자리 걷기 | 10~15회 | 발을 높이 들지 않고 발바닥을 살짝 번갈아 든다. |
| 4 | 발뒤꿈치 들기 | 10~15회 | 발 앞꿈치는 바닥에 두고 뒤꿈치만 살짝 든다. |
| 5 | 힘 빼기 | 10초 | 다리 힘을 빼고 편하게 쉰다. |

### 2.4 앱 반복 단계: 무릎 펴기

| 순서 | 화면 단계 문구 | 자세 설명 | 복실이 음성 예시 | 캐릭터 동작 |
|---:|---|---|---|---|
| 1 | 발끝 당겨요 | 발끝을 몸 쪽으로 살짝 당긴다. | `발끝을 몸 쪽으로 살짝 당겨요. 허벅지 앞쪽에 힘이 들어오면 좋아요.` | 발목이 몸 쪽으로 굽는다. |
| 2 | 종아리 앞으로 | 허벅지는 의자에 두고 무릎 아래 종아리만 앞으로 편다. | `허벅지는 의자에 두고, 종아리만 앞으로 천천히 펴요.` | 무릎 아래 다리가 앞으로 펴진다. |
| 3 | 무릎 편 채 유지 | 무릎을 편 채 잠깐 멈춘다. 무릎을 세게 잠그지 않는다. | `잠깐 멈춰요. 무릎은 세게 잠그지 않아도 됩니다.` | 다리가 펴진 상태로 유지된다. |
| 4 | 천천히 내려요 | 발을 바닥에 쿵 내려놓지 않고 천천히 내린다. | `발을 쿵 내려놓지 말고 천천히 내려요.` | 종아리가 천천히 아래로 돌아온다. |
| 5 | 힘 빼요 | 발끝 힘을 풀고 다리 힘을 잠깐 뺀다. | `좋아요. 힘을 잠깐 빼고 다음 동작 준비해요.` | 발이 편하게 바닥에 놓인다. |

### 2.5 중단 기준

- 무릎 앞쪽에 날카로운 통증이 있다.
- 허리가 당기거나 뒤로 젖혀진다.
- 발을 내릴 때 쿵 떨어뜨리게 된다.
- 숨이 차거나 어지럽다.

### 2.6 앱 구현 메모

| 항목 | 값 |
|---|---|
| 기본 단계 | 1단계 10회 x 3세트, 2단계 12회 x 4세트, 3단계 15회 x 5세트 |
| 권장 속도 | 한 단계 1.3초 이상 |
| 강조 관절 | 발목, 무릎, 발 |
| 안전 문구 | `무릎을 세게 잠그지 말고, 아프면 바로 쉬어요.` |

## 3. 누워서 운동

### 3.1 목적

허리와 무릎에 부담을 줄이면서 허벅지 앞쪽 근육을 천천히 사용한다. 무릎 운동을 하되 서기 어렵거나 의자 운동 다음 단계가 필요한 사용자에게 적합하다.

### 3.2 준비물과 자세

| 항목 | 설명 |
|---|---|
| 장소 | 바닥 매트 또는 단단한 침대. 너무 푹신한 곳은 피한다. |
| 기본 자세 | 등을 대고 눕는다. 한쪽 무릎은 세워 허리를 편하게 둔다. |
| 운동할 다리 | 무릎을 편 상태로 바닥에 둔다. |
| 허리 | 허리가 바닥에서 뜨지 않게 한다. 뜨면 다리를 더 낮게 든다. |
| 목/어깨 | 목과 어깨 힘을 뺀다. |

### 3.3 추천 루틴

| 단계 | 운동 | 횟수 | 설명 |
|---|---|---:|---|
| 1 | 발끝 당기기 | 10회 | 누운 상태에서 발끝을 몸 쪽으로 당긴다. |
| 2 | 낮은 다리 들기 | 10~15회 | 무릎을 편 다리를 바닥에서 약 10cm만 든다. |
| 3 | 발꿈치 밀기 | 10회 | 발꿈치를 바닥에 대고 다리를 길게 민다. |
| 4 | 무릎 좌우 흔들기 | 10회 | 무릎을 세운 상태에서 좌우로 작게 흔든다. |
| 5 | 편안 호흡 | 3회 | 코로 들이마시고 입으로 길게 내쉰다. |

### 3.4 앱 반복 단계: 낮은 다리 들기

| 순서 | 화면 단계 문구 | 자세 설명 | 복실이 음성 예시 | 캐릭터 동작 |
|---:|---|---|---|---|
| 1 | 발끝 당겨요 | 운동할 다리의 발끝을 몸 쪽으로 살짝 당긴다. | `발끝을 몸 쪽으로 살짝 당겨요. 무릎은 편 채로 준비해요.` | 발끝이 몸 쪽으로 굽는다. |
| 2 | 다리 10cm 들어요 | 무릎을 편 다리를 바닥에서 손바닥 한 뼘보다 낮게 든다. | `다리를 높이 들지 말고 10cm만 들어요.` | 편 다리가 낮게 올라간다. |
| 3 | 허리 붙이고 유지 | 허리가 바닥에서 뜨지 않는지 확인하며 잠깐 유지한다. | `허리가 뜨지 않게 확인하고 잠깐 멈춰요.` | 다리가 낮게 든 상태로 유지된다. |
| 4 | 천천히 내려요 | 다리를 천천히 내려 바닥에 놓는다. | `다리를 천천히 내려요. 바닥에 툭 놓지 않아요.` | 다리가 바닥으로 천천히 내려간다. |
| 5 | 힘 빼요 | 발끝 힘을 풀고 숨을 편하게 쉰다. | `발끝 힘을 풀고 숨을 편하게 쉬어요.` | 다리가 바닥에 놓이고 얼굴이 편안해진다. |

### 3.5 중단 기준

- 허리가 바닥에서 뜬다.
- 허리에 찌릿하거나 당기는 느낌이 있다.
- 다리를 들 때 무릎이 아프다.
- 다리를 높이 들어야 한다고 느껴 무리하게 된다.

### 3.6 앱 구현 메모

| 항목 | 값 |
|---|---|
| 기본 단계 | 1단계 10회 x 3세트, 2단계 12회 x 4세트, 3단계 15회 x 5세트 |
| 권장 높이 | 약 10cm, 높이보다 허리 안정 우선 |
| 강조 관절 | 발목, 무릎, 허리 안정 |
| 안전 문구 | `허리가 뜨면 다리를 더 낮게 들어요.` |

## 4. 집안에서 하는 가벼운 운동

### 4.1 목적

집 안에서 벽, 식탁, 안정된 의자를 잡고 아주 작은 움직임으로 다리와 균형 감각을 유지한다. 서서 하는 동작이므로 안전 지지물이 가장 중요하다.

### 4.2 준비물과 자세

| 항목 | 설명 |
|---|---|
| 지지물 | 벽, 무거운 식탁, 고정된 손잡이. 바퀴 의자 금지. |
| 발 위치 | 양발은 골반 너비로 벌린다. |
| 손 | 양손 또는 한 손으로 지지물을 가볍게 잡는다. |
| 시선 | 바닥보다 정면을 본다. |
| 움직임 | 작게, 천천히, 흔들리지 않게 한다. |

### 4.3 추천 루틴

| 단계 | 운동 | 횟수 | 설명 |
|---|---|---:|---|
| 1 | 지지물 잡기 | 10초 | 지지물이 흔들리지 않는지 확인한다. |
| 2 | 뒤꿈치 들기 | 10~15회 | 발 앞꿈치는 바닥에 두고 뒤꿈치만 살짝 든다. |
| 3 | 짧은 제자리 걷기 | 10~15회 | 무릎을 높이 들지 않고 발만 번갈아 든다. |
| 4 | 옆으로 다리 벌리기 | 10회 | 한쪽 다리를 옆으로 조금만 벌렸다가 돌아온다. |
| 5 | 균형 잡기 | 5초 | 양발을 바닥에 두고 숨을 고른다. |

### 4.4 앱 반복 단계: 뒤꿈치 들기

| 순서 | 화면 단계 문구 | 자세 설명 | 복실이 음성 예시 | 캐릭터 동작 |
|---:|---|---|---|---|
| 1 | 잡아요 | 벽이나 식탁처럼 흔들리지 않는 곳을 가볍게 잡는다. | `먼저 흔들리지 않는 곳을 잡아요.` | 손이 지지물을 잡는다. |
| 2 | 뒤꿈치만 들어요 | 발 앞꿈치는 바닥에 두고 뒤꿈치만 살짝 든다. | `앞꿈치는 바닥에 두고, 뒤꿈치만 살짝 들어요.` | 발뒤꿈치가 위로 올라간다. |
| 3 | 잠깐 유지 | 손, 무릎, 허리가 편한지 확인한다. | `몸이 흔들리지 않는지 잠깐 확인해요.` | 뒤꿈치를 든 상태로 유지한다. |
| 4 | 천천히 내려요 | 뒤꿈치를 바닥으로 천천히 내린다. | `뒤꿈치를 천천히 내려요.` | 발이 바닥으로 돌아온다. |

### 4.5 중단 기준

- 지지물이 흔들린다.
- 몸이 한쪽으로 크게 기울어진다.
- 발목, 무릎, 허리가 아프다.
- 숨이 차서 말하기 어렵다.

### 4.6 앱 구현 메모

| 항목 | 값 |
|---|---|
| 기본 단계 | 1단계 10회 x 3세트, 2단계 12회 x 4세트, 3단계 15회 x 5세트 |
| 권장 위치 | 벽 또는 무거운 식탁 옆 |
| 강조 관절 | 발, 발목, 무릎, 손 |
| 안전 문구 | `움직이는 의자는 잡지 않아요.` |

## 5. 장운동

### 5.1 목적

복부를 강하게 자극하는 운동이 아니라, 호흡과 부드러운 움직임으로 몸을 편안하게 풀어 주는 모드다. 무릎 운동을 하기 어려운 날에도 앱을 열어 루틴을 유지할 수 있게 돕는다.

### 5.2 준비물과 자세

| 항목 | 설명 |
|---|---|
| 자세 | 의자에 앉거나 누워서 편한 자세를 선택한다. |
| 손 | 배 위에 가볍게 올린다. 누르지 않는다. |
| 호흡 | 코로 들이마시고 입으로 길게 내쉰다. |
| 복부 마사지 | 시계방향으로 아주 부드럽게 문지른다. |
| 허리 | 허리가 불편하면 범위를 줄이거나 중단한다. |

### 5.3 추천 루틴

| 단계 | 운동 | 횟수/시간 | 설명 |
|---|---|---:|---|
| 1 | 복식호흡 | 3회 | 손을 배 위에 올리고 숨을 천천히 쉰다. |
| 2 | 배 시계방향 마사지 | 20초 | 배를 세게 누르지 않고 시계방향으로 문지른다. |
| 3 | 무릎 좌우 흔들기 | 10회 | 누운 상태에서 무릎을 세우고 좌우로 작게 흔든다. |
| 4 | 발목 펌프 | 10회 | 발끝을 몸 쪽으로 당겼다가 편하게 푼다. |
| 5 | 편안한 휴식 | 20초 | 눈을 감고 호흡을 고른다. |

### 5.4 앱 반복 단계: 복식호흡

| 순서 | 화면 단계 문구 | 자세 설명 | 복실이 음성 예시 | 캐릭터 동작 |
|---:|---|---|---|---|
| 1 | 숨 들이마셔요 | 배 위에 손을 가볍게 올리고 코로 숨을 들이마신다. | `배를 세게 누르지 말고 숨을 천천히 들이마셔요.` | 배와 몸통이 살짝 올라간다. |
| 2 | 잠깐 멈춰요 | 어깨 힘을 빼고 잠깐 멈춘다. | `어깨 힘은 빼고 잠깐 멈춰요.` | 캐릭터가 편안한 표정으로 멈춘다. |
| 3 | 길게 내쉬어요 | 입으로 숨을 길게 내쉰다. | `입으로 길게 내쉬며 배와 허리를 편하게 풀어요.` | 몸통이 살짝 내려간다. |

### 5.5 앱 반복 단계: 배 시계방향 마사지

| 순서 | 화면 단계 문구 | 자세 설명 | 복실이 음성 예시 | 캐릭터 동작 |
|---:|---|---|---|---|
| 1 | 손 올려요 | 손을 배 위에 가볍게 올린다. | `손을 배 위에 살짝 올려요. 누르지 않아도 됩니다.` | 손이 배 위로 온다. |
| 2 | 시계방향으로 | 배꼽 주변을 시계방향으로 작게 문지른다. | `시계방향으로 아주 부드럽게 문질러요.` | 손이 둥글게 움직인다. |
| 3 | 힘 빼요 | 손 힘을 빼고 배를 편하게 둔다. | `좋아요. 배에 힘을 빼고 편하게 쉬어요.` | 손과 몸이 편안하게 멈춘다. |

### 5.6 중단 기준

- 배를 누를 때 통증이 있다.
- 어지럽거나 메스꺼운 느낌이 있다.
- 식후 바로 강하게 누르고 싶어진다.
- 허리가 불편하다.

### 5.7 앱 구현 메모

| 항목 | 값 |
|---|---|
| 기본 단계 | 1단계 10회 x 3세트, 2단계 12회 x 4세트, 3단계 15회 x 5세트. 마사지는 20~30초 안에서 조절 |
| 권장 속도 | 매우 느리게 |
| 강조 부위 | 손, 배, 호흡, 허리 편안함 |
| 안전 문구 | `배를 세게 누르지 않아요.` |

## 6. 앱 데이터 구조 제안

운동 순서를 앱 코드로 옮길 때는 아래 구조를 사용할 수 있다.

```js
{
  mode: 'seated',
  title: '앉아서 운동',
  steps: [
    { label: '발끝 당겨요', cue: '발끝을 몸 쪽으로 살짝 당겨요.', pose: 'phase-toe' },
    { label: '종아리 앞으로', cue: '무릎 아래 종아리만 앞으로 천천히 펴요.', pose: 'phase-lift' },
    { label: '무릎 편 채 유지', cue: '무릎을 편 채 잠깐 멈춰요.', pose: 'phase-hold' },
    { label: '천천히 내려요', cue: '발을 쿵 내려놓지 말고 내려요.', pose: 'phase-lower' },
    { label: '힘 빼요', cue: '다리 힘을 잠깐 빼요.', pose: 'phase-ready' }
  ]
}
```

## 7. 우선 적용 순서

1. 앉아서 운동: 가장 안전한 기본 루틴으로 먼저 완성한다.
2. 누워서 운동: 허리 주의 문구와 낮은 다리 들기 동작을 정확히 만든다.
3. 집안 가벼운 운동: 지지물 안전 안내를 먼저 띄운다.
4. 장운동: 호흡과 마사지 중심으로 천천히 구현한다.

## 8. 영상 분석 기반 추가 운동

여섯 편의 YouTube Shorts에서 확인한 다리운동은 70대 사용자에게 맞게 자세와 범위를 낮춰 앱의 다리운동 방법 화면에 추가했다.

- 앉아서: 양쪽 다리 펴고 유지, 발 방향 바꾸고 무릎 펴기, 일어나기 전 허벅지 힘주기
- 누워서: 뒤꿈치 미끄러뜨리기, 누워서 무릎 벌리기, 조개껍질 운동
- 서서: 지지물 잡고 작은 옆걸음
- 기본 제외: 깊은 무릎 굽힘 저항, 무릎 플랭크, 눈 감고 외발 서기, 불안정한 도구, 깊은 사이드 런지
