# 복실이 새 캐릭터 적용 가이드

문서 버전: v0.1  
작성일: 2026-08-11  
기준 이미지: `public/assets/characters/bokshil-master-sheet.png`

## 1. 적용 원칙

이 앱의 캐릭터 기준은 `backup` 폴더의 이전 이미지나 이전 문서가 아니라, 새로 첨부된 복실이 캐릭터 마스터 시트다. 앱 구현, 추가 이미지 생성, 애니메이션 프롬프트는 이 문서를 기준으로 한다.

## 2. 복실이 기본 형태

| 항목 | 기준 |
|---|---|
| 선 | 검정색 두꺼운 외곽선 |
| 얼굴 | 흰 원형 얼굴, 세로 타원 눈, 큰 웃는 입 |
| 볼 | 연한 분홍 볼터치 |
| 몸 | 흰 타원형 몸통 |
| 팔/다리 | 단순한 검정 선, 손과 발은 둥글게 표현 |
| 무릎 표시 | 한쪽 무릎에 분홍 원형 포인트 |
| 분위기 | 70대 어른에게 친근한 운동 친구, 잔소리보다 칭찬 |

## 3. 표정 세트

| 상태 | 사용 상황 | 화면 적용 |
|---|---|---|
| 웃는 얼굴 | 기본, 홈, 반가움 | 홈 첫 상태 |
| 신나는 얼굴 | 성공, 칭찬, 완료 | 운동 완료, 3회 완료 |
| 힘내는 얼굴 | 운동 시작, 어려운 구간 | 운동 중 격려 |
| 주의하는 얼굴 | 자세 주의, 허리 안내 | 준비 자세, 안전 문구 |
| 아픈 얼굴 | 통증, 불편함, 중단 안내 | `아파요` 선택 후 |
| 쉬는 얼굴 | 휴식, 마음 편안할 때 | 잠깐 쉬기 |
| 놀라는 얼굴 | 갑작스러운 상황, 주의 | 안전 경고 강조 |

## 4. 운동 동작 세트

| 모드 | 필수 표현 |
|---|---|
| 앉아서 하기 | 의자에 앉아 무릎 펴기, 발목 당기기, 발끝 올리기 |
| 누워서 하기 | 무릎 하나 세우기, 낮은 다리 들기, 허리 바닥 유지 |
| 집안 가벼운 운동 | 의자 또는 안정 지지물 잡기, 제자리 걷기, 뒤꿈치 들기 |
| 장운동 / 편안 운동 | 복식호흡, 배 시계방향 마사지, 무릎 좌우 흔들기, 편안한 휴식 |

## 5. 금지 사항

- 실사풍 고령자 이미지로 대체하지 않는다.
- 복잡한 근육/관절 해부 그림처럼 만들지 않는다.
- 무릎 통증을 공포스럽게 표현하지 않는다.
- 실패, 시듦, 꾸중, 벌점 표현을 쓰지 않는다.
- `backup` 문서의 이전 이미지 프롬프트를 기준으로 삼지 않는다.

## 6. 현재 앱 반영 현황

- CSS 기반 복실이 캐릭터를 새 시트 스타일로 구성했다.
- 홈, 완료, 안전 중단 상태에서 표정이 바뀐다.
- 한쪽 무릎의 분홍 표시를 캐릭터와 운동 피규어에 반영했다.
- 새 캐릭터 시트는 public/assets/characters/bokshil-master-sheet.png를 개발 기준 자산으로 사용한다.
